# Display
An hardware Display Project. It comprises a Led Matrix and buttons. When a particular button is picked it randomly select from a set of possible categories and then display it. For example the first button would randomly display Y or N using the led, which represent Yes or No respectively. <br>

At this stage the full project is still in the design phase. <br>
